テスト通知

統計

個人を特定できる情報は保存せず、件数のみを集計しています。日付は UTC、時間帯・曜日は JST です。

キャラ別の絆ランキング

1人は1キャラにつき1つの枠にだけ数えます(50 未満はどの枠にも入りません)。「登録」はそのキャラを1回でも登録したことのあるユーザー数です。

タップテスト

タップの記録・統計には一切書き込みません。指定した時刻にタップした場合に何が起きるか(論理月・統計キー・通知予約)を確認します。

通知の通し確認

60秒後に、この管理者の端末へ通常のタップ通知を届くよう実際に予約します(cron → FCM の経路の確認)。届くまで最大1〜2分かかります。

キャラクターのコード作成

作ったコードを src/gamedata.js に貼ってデプロイすると、アプリに追加されます(この画面では保存しません)。好きな贈り物をタップして効果を選びます(タップするたびに 未選択 → 通常・中 → 通常・大 → 通常・特大 → 高級・大 → 高級・特大 → 未選択)。中国語・韓国語が空欄なら英語名を使います。
